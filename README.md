# Drug Side Effect Predictor

## Background & Motivation
This project is part of a structured 6-week internship in data analytics and software development. It focuses on applying statistics, Python, and machine learning skills to a real-world, health-adjacent dataset through an end-to-end data science workflow.

## Project Scope
**Multi-label classification:** Given a drug's known attributes (categorical and textual), predict the set of side effects historically associated with that drug using a public drug–side-effect association dataset (e.g., SIDER).

**Explicitly out of scope for v1:**
- Patient-specific personalization (age/gender-adjusted risk)
- Severity or frequency grading of side effects
- Drug-drug interaction modeling

> [!WARNING]
> **Medical Disclaimer**
> This project is explicitly a learning and portfolio project. It is **not intended for clinical, diagnostic, or real-world medical use at any stage**. Predictions generated by this model are based on statistical associations in historical data and must not inform real medical decisions.
